# Material Mundi
Turn Waste Into Value. A secure, production-quality full-stack MERN marketplace for waste material sourcing and processed material sales.

## Quick Start

- Install: npm install
- Dev: npm run dev (server + client)
- Build: npm run build
- Tests (server): npm run test
- Seed (dev): npm run seed -w server

See docs/API.md for API contract. Full end-to-end workflow verified via unit/integration tests (54 tests passing).
